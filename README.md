# Sistema de Ventas Multi-Tienda

Sistema genérico de registro de ventas para cualquier tipo de negocio.

## Características

- Asistente inicial: nombre, logo, moneda y tipo de tienda
- Tipo de tienda **bloqueado** una vez elegido
- Productos con categorías según el tipo de negocio
- Punto de venta (carrito + cobro)
- Historial de ventas y panel de métricas
- Ajustes: se puede cambiar nombre/logo/moneda, no el tipo

## Tipos de tienda

Abarrotes, Ropa, Electrónica, Restaurante, Farmacia, Ferretería, Belleza y Tienda general.

## Instalación

El instalador queda en:

`dist-installer\SistemaVentas-Setup-1.0.0.exe`

- Crea acceso directo en escritorio y menú inicio
- Cada PC/instalación guarda sus datos aparte
- Datos de la app instalada: `%APPDATA%\sistema-ventas\data`
